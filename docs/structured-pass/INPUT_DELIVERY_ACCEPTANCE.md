## Refusals and deliberate faults

The new tests cover exact character pagination, empty and later pages, invalid
origins and IDs, traversal, symlinks, missing and same-size changed payloads,
profile/catalog drift, stale generations, invalid analogue selectors, media
identity drift and ordinary root/source-path refusal. Notes-advisory tests cover
absent, canonical-only, root-only and duplicate locations without changing exit
status.

Six in-memory faults each make the corresponding test fail: skipping input
hash validation, dropping a retained payload, omitting a role item, accepting a
wrong page identity, selecting the wrong analogue model and removing the notes
advisory. Production files are not mutated by these controls.

Final validation passed: 341 structured tests (one opt-in skip), all 692 shell
tests and 1,206 Java tests through `make test`, strict playbook and repository
hygiene checks, `git diff --check`, and 101 relative links/anchors. The shared
diff is project-neutral. All ten new tests are included in the structured run.

The process wrapper was measured on the largest local assembly source in a
disposable clone, with pinned tools, one warmup per mode and three alternating
before/after pairs under the shared heavy-run lock. Both modes completed the
same passing checks. Median wall time changed by **−0.62%**, within the 5%
limit; this is non-regression evidence, not a speedup claim. Wall/user/system
times, spread, machine identity and tool hashes remain in the private record.
