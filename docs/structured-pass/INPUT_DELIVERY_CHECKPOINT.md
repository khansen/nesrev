## Contract for continuation

1. **Operator-owned admission.** Declare inputs during preparation, outside both
   agent workspaces. Kinds are fixed: guidance, supplied-reference text/media,
   historical intake evidence and selected analogue context. Guidance comes from
   the fixed repository list; comparison docs come from the selected projects
   and the architecture index at the pinned commit. No caller-provided path or
   additional input is accepted through an agent operation. Check copied bytes,
   reject symlinks/traversal/duplicate IDs and bind the admitted manifest to the
   profile and starting generation. A later manifest edit cannot admit a file.
2. **Retained identity.** Copy the admitted catalog and payloads into hashed
   captures, carried through candidates, publication and retained restore.
   Reuse the existing capture/blob integrity checks. Generation plus input ID
   selects content; missing or changed payloads fail. Original paths and source
   hashes are provenance, never permission to reopen a host path. Restored reads
   must work after the original input directory is unavailable.
3. **Bounded reads.** Add a catalog operation and a paged input reader accepting
   fixed IDs, generation and bounded pagination. Keep the 24 KiB wire ceiling,
   exact content, explicit completion and no silent truncation. Guidance retains
   its existing entry point with retained copies for new sessions; old profiles
   retain their existing behavior. Both corridor roles and retained reviews
   receive the declared evidence. Inputs are not new authored-document paths.
4. **Analogue navigation.** An optional validated index selects one of the two
   captured native models in existing symbol/record/use/comment navigation.
   Return its model identity with the response. Keep the current record engine,
   two-model cap and source isolation. No new search engine, corpus discovery,
   free-path read or naming authority is introduced. Required comparison queries
   must fit the fixed eight-request limit through the actual bridge.
5. **Role assembly.** Keep active task instructions separate from historical
   receipt/review content. Build both role input inventories from one manifest;
   map page IDs to their pinned PNG copies through the existing adapters.
   Prove equality offline without credentials, model calls or installing a live
   permission profile. The launcher still owns real client/tool-declaration
   admission and the hook-disabled reviewer test.
6. **Notes advisory.** Add a nonblocking root-notes warning to the existing
   process check, including duplicate root/canonical copies. Canonical-only and
   absent notes stay quiet. Do not repair other projects in this slice.

Proposed input limits accommodate this measured inventory without unbounded
admission: 32 text items, 256 KiB per text and 2 MiB total; 16 media items,
16 MiB per media and 64 MiB total. The existing two-model cap and response
ceiling remain unchanged. These are maximums, not a reason to fill the catalog.
Inputs outside these limits return for a decision rather than being truncated.
