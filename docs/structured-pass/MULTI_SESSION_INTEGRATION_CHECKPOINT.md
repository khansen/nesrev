## Service and native evidence

The investigation service offers read operations, citation resolution and
checkpoint submission. It independently refuses editing. The ordinary corridor
also refuses mutation while its investigation admission gate is closed.

Each delivered bridge response is journaled by arguments and full text hash.
The coordinator matches that journal to the finished native session's actual
tool outputs, in order. Stream IDs and native IDs are not conflated. An orphan
blob or staged checkpoint cannot satisfy a transition. Publication is an atomic
pointer to an immutable capture, using the existing store and editor lock.

Claims include a subject, confidence, native or fixed-input citations, unknowns,
contrary evidence and optional dependencies/conflicts. Input citations require
the exact hash and complete delivered character span. Only actual outputs after
the last compaction count. Every consumer repeats the native audit and parent
checks. Declared conflicts block editor admission; semantic contradictions that
the model did not identify still require the editor and independent reviewer.
Delivery receipts do not prove understanding.

The native configuration proof used **two of ten allowed invocations**, on
loopback under the network restriction, with dummy authentication and no
provider calls. An investigator read evidence and staged a checkpoint. The
coordinator reconciled its native output and reopened the workflow. A fresh
editor, using the same isolated provider home, received the checked handoff,
resolved an edit target and confirmed a synthetic draft. The first request
contained no earlier tool conversation or investigator-only marker. No
application was attempted.

The investigation declaration was captured and pinned from the client request.
Subsequent subject/input-span/partition-cap additions are covered by service
tests, not retroactively attributed to those native runs. The generated phase
contract is fetched through the real bridge in tests. The ordinary tool help
now distinguishes text inputs from fixed record pages; its previous Codex and
Claude capture fixtures intentionally remain stale pending the final recipe.
Those profiles are not newly admitted.

Profiles can be prepared before investigation completes. Initial editor
admission permits only the service-checked investigation receipt to change
from the sealed editor state; changing any other field still refuses. Fresh
contexts cannot reuse a previously present native thread ID. Ordinary resumed
editing turns retain their existing thread behavior.
